[ LIVE TRANSIT TRACKER ]

OttaTransit

A live OC Transpo tracker that maps nearby stops and shows real-time arrival countdowns for each route. An Express proxy decodes GTFS-Realtime protobuf feeds (sidestepping CORS and hiding the API key) and serves an in-memory snapshot refreshed every 15 seconds, while vehicles are animated between updates by dead reckoning from speed and bearing.

ReactViteMapLibre GLNode.jsExpressTanStack Query

[ TRIP PLANNER ]

TipRoute

A trip planner that estimates time, budget, and difficulty for multi-country, tip-to-tip routes. Its dual-mode engine estimates the day range for a given route, or the reachable distance and checkpoint for a set number of days.
